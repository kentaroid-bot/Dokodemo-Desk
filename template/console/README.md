# 読み取りUI

`python3 -B console/server.py` で起動。標準のポートは8772です。ほかの画面と重なるときは `--port 8773` を付けます。原本の変更後は「記録を更新」を押します。外部通信・アカウント探索・通知・編集のAPIはありません。

読み取るものは担当名簿、仕事の共通欄、日報・月報、回覧・メール共有です。目的、導入記録、総えもんの案内とGitHub保存再開の入口も表示します。Markdownの本文と、その本文からリンクされた仕事場内のMarkdown原本を表示します。隠しファイル、runtime、仕事場外は表示しません。

work_records.pyとboards.pyはMonku_AIの試作から移した読み取り部です。このフォルダが展開先の原本で、元のMonku_AIへは参照しません。変更時は名簿追加・作業票更新・原本リンク・欠損表示・狭い画面を確認してください。

通知とモデル使用量は環境別の追加機能です。未接続を0件・0トークンとして扱いません。バックグラウンドの常時巡回もありません。
