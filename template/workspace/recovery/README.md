# 保存と戻し方

別端末との共有には[GitHubで保存・再開](github.md)も選べます。このページは外部へ送らず、手元で保存する方法です。

大きな変更の前に、この仕事場の外へZIPを保存します。既存のZIPと復元先は上書きしません。これはローカル保存で、外部への送信はしません。

## 保存する

仕事場のフォルダで実行します。名前はその都度変えてください。

```text
python3 -B workspace/recovery/manage.py backup ../workplace-before-change.zip
```

共通文書、仕事の記録、成果物、画面を含みます。隠しファイル（.gitignoreを除く）、runtimeの接続情報、ZIP、リンク先は含めません。必要な外部素材や実行環境の再設定は別に記録します。保存する間は対象の編集を止め、保存直後の状態を確かめます。

## 別の場所へ戻す

```text
python3 -B workspace/recovery/manage.py restore ../workplace-before-change.zip --to ../workplace-restored
```

復元先のconsole/server.pyをPythonで起動します。元の画面と同時に開く場合は `--port 8773` のように別の番号を使います。目的・導入記録・担当・仕事・成果物が保存時の状態で開けることを確認し、元のフォルダを残したまま比較します。総えもんは導入記録を読み、準備済みの役割を作り直さず、次の一手から案内します。

この道具は512MiBまでの保存ZIPの復元を対象にします。大きな素材が増えたら、総務と保存方法を見直してください。保存の定期実行は設定していません。
