# 共有板

回覧はitemsへMarkdownで置き、問い・対象者・返答を同じ原本に記します。全員の実際の返答がそろったら総務がまとめて閉じ、削除せず保存します。メール共有はmail/bulletinsの原本を読みます。メール取得自体は未接続です。

回覧の冒頭は `---` で囲み `status: open` または `status: closed` を記します。本文に題名、作成日時、発議者、返答期限、対象と回答状況の表、問いと返答を置きます。表は担当ID・状態・記録日時の3列。状態は未読、確認済み・未回答、回答済みなど、実際の記録を使います。

画面の閲覧は既読や返答を代行しません。設置や回覧の投稿で作業範囲・権限を増やしません。
