# ＜仕事の名前＞

ひな形です。operations/jobs/<作業ID>/TASK.mdへコピーし、説明と未記入箇所を実際の内容に直してください。現在地は一件につき一つだけにします。

<!-- monku-work:v1 -->
## 仕事の現在地
- 作業ID: ＜英小文字・数字・ハイフン＞
- 件名: ＜何の仕事か＞
- 担当: ＜名簿の担当ID＞
- 関係する担当: ＜必要なら担当IDをカンマで区切る。不要なら行を削除＞
- ステータス: ＜実際に確認した状態＞
- 更新日時: ＜2026-10-07T10:00:00+09:00 の形式＞
- 目的: ＜何を実現するか＞
- 次の一手: ＜次に誰が何をするか＞
- 今回の到達点: ＜どこまで実施して止めるか＞
- 報告先: ＜人が分かる窓口名＞
- 成果: ＜成果物・確認結果。未完成ならその状態＞
<!-- /monku-work -->

## 依頼・許可範囲

本人の依頼、対象、重要な訂正、判断。本人の発言とAIの解釈を分けます。

仕事場の目的（workspace/purpose.md）と今回の依頼の関係を必要な分だけ記します。本人が目的を変更した場合は共通原本にも反映し、古い目的で今回の指示を上書きしません。

## 成果と検証

成果物への相対リンク、試したことと結果、確定事項と未確認を記します。

## 引き継ぎ

残る仕事、次の担当と行動、許可範囲・終了点・期限・停止条件、報告や受け渡しの状態。必要な分だけ記し、毎回別の票を増やしません。
