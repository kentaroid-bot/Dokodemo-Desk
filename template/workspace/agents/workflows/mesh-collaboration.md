# メッシュを介して、他のどこでもデスクと繋がる

別々の仕事場が知識や問いを持ち寄り、それぞれの成果と理解を豊かにしたいときに使う。[どこでもメッシュ](https://github.com/kentaroid-bot/dokodemo-mesh)は、そのあいだに置く「中庭」のテンプレート兼仕様モック。

この仕事場の内部で係や専門デスクを増やすだけなら、[担当を増やす手順](add-desk.md)を使う。外との協働を始めたいときに、総えもんが以下を案内する。

## 1. 何のために繋がるかを整理する

誰と何を一緒に考え、どんな成果を持ち帰りたいかを、本人の依頼から整理する。既に分かることを聞き直さず、不足する前提だけ確かめる。相手の参加意思が未確認なら提案として残す。

中庭を維持・拡大することを目的にしない。自分の複数の仕事場でも、他人の仕事場との協働でもよい。協働を必要としない仕事まで接続しない。

## 2. 中庭を用意し、共有する範囲を揃える

メッシュのREADMEとagreements.mdを読み、空のテンプレートを別フォルダやリポジトリへ用意する。既存の目的・業務記録を上書きしない。公開テンプレートの取得と、実務の中庭の公開は別。実務の共有先と読み書きできる参加者を、今回の依頼範囲に合わせる。

この連携では **Desk ↮ Desk / Desk ↔ Mesh / Mesh ↔ Mesh** を守る。相手の内部へ直接入らず、中庭の静的データを読む。原本は各デスクに保ち、必要な要約・抜粋・提案を選んで置く。内部履歴や私的な資料を丸ごと複製しない。外への持ち出しを認めていない情報は、中庭にも載せない。

別の中庭と繋ぐ場合も、そのあいだに同じ形式の中庭を置く。外側の合意を、こちらの内部の判断へ自動適用しない。

## 3. 最初の約束を、参加デスク全員で決める

中庭のpurpose.md・desks.md・agreements.mdを埋め、各デスクへ持ち帰って検討する。次の4条件を満たすことを確認する。

- **非私有性**：保存場所の管理担当が、規約や参加者を独断で支配しない。
- **非蓄積性**：成果と必要な理由を、各デスクへ持ち帰れる。
- **全員合意**：初回採用と規約変更は、全参加デスクが同じ案へ明示的に合意する。
- **完全な解消可能性**：いつでも退出でき、成果を持ち帰って中庭を閉じられる。

共有範囲・成果の利用条件・管理権限・持ち帰り方法・終了時の扱いを揃える。未応答や保留を合意に数えず、相手の返答を代筆しない。違いや保留は作業票に残す。条件が揃わない場は、メッシュとして接続せず準備中にする。

## 4. このデスクの巡回担当を決める

最初は総えもんや既存担当が兼務できる。新しい係が必要なら [担当を増やす手順](add-desk.md) で役割を定め、[名簿](../registry.md)へ登録する。係の設置だけで別AIや定期処理を起動しない。

巡回担当の役割原本へ、必要な分だけ次を記す。

- 中庭の場所と読む入口、共同作業票への参照。
- 読んでよい情報、共有してよい内容、任された回答・判断の範囲。
- 持ち帰って相談する担当や人間、前回確認した案・更新の位置。
- 手動か定期か、頻度と実際の起動設定、止める方法。

新しい外部送信・認証・定期起動は、本人の依頼と利用環境の許可に沿って設定する。案内や役割文書を置いただけで接続済み・稼働中とは報告しない。

## 5. 読む・持ち帰る・考える・返す

1. 中庭の約束と、自分に関係する新しい問い・返答を読む。
2. 目的や理由とともに自分の仕事場へ持ち帰り、必要な人やAIと検討する。
3. 任された範囲で、同じ共同作業票へ回答・提案・成果を返す。
4. 次に誰の何を待つかを記す。成果を使ったら、役立った点や合わなかった理由も必要な分だけ返す。

「持ち帰り／検討中／提案／合意／保留」を区別する。「引き受ける」なら担当と範囲も記す。共同のやり取りは中庭の作業票、こちらで引き受けた実作業はこの仕事場の作業票を原本にし、参照で結ぶ。同じ進捗を二重管理しない。

対立したら、人の人格ではなく提案・根拠・適用条件を検討する。意見の違いや保留理由を一つの結論へ丸めない。約束を変えたいときも、中庭の作業票で提案し、全員の返答を経て改訂する。

## 6. 持ち帰って、休む・終える

役立つ成果と判断理由を自分の仕事場へ保存し、中庭へのリンクだけに依存しない形にする。途中の仕事は引き継ぐか保留を記し、任された巡回を止める。退出に全員の承認は要らない。共有物は合意した終了手順に沿って扱い、相手の記録を無断で消さない。

この案内は接続のための運用手順。アクセス制御や自動同期の実装ではない。既存の仕事場へ取り込む際も、本人の目的・役割・記録を保ち、必要な箇所だけ追加する。
