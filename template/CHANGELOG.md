# 変更履歴

## 2026-10-10 — 動機の伴走役の続き方

- 本人の「これを記録して」とAIからの気づきを入口に、仕事を通して動機の理解を育てる手順を加えた。
- purpose.mdへ現在の目的とそこへ至った歩みを残し、初回案内・業務記録・伴走役のひな形と練習例からつないだ。
- 既存の仕事場へ取り込む場合は、本人の目的・役割の内容を保持して、この手順を必要な箇所へ追記する。

## 2026-10-10 — 初期公開版の雛形 v0.2

- 総えもんとUI担当から始め、本人の動機に伴走する担当を対話から加える手順を用意した。
- 共通の係はロール文書、専門担当は担当定義と仕事の案内を含むデスク文書にまとめ、名簿から探せる。
- 導入作業を最初のTASKに記録し、onboarding.mdから同じ原本を参照する。
- 担当・仕事・日報・共有板・案内を読むローカルUIと、GitHub・ZIPによる保存・再開の手順を備える。
- 空の版は2担当・0仕事、練習版は架空の4担当・1仕事から始まる。
- 継続業務の専用チャットへの案内と、同じチャットで続ける選択肢を用意した。
- MITライセンスの許諾表示を同梱した。

MVPでの改善をまとめた公開版の出発点。役割の自動生成、チャットの自動起動、通知、プラグインは未実装。

## 更新を受け取るとき

導入先で変更した文書が運用原本。新しい雛形は別フォルダへ展開し、版と変更点を比較して必要な箇所だけ取り込む。仕事場全体を上書きせず、目的・担当・仕事・保存設定を保持する。採用した変更はここに日付・理由とともに追記できる。
