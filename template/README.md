# どこでもデスク｜自分たちで育てるAI仕事場

**机の引き出しから、相棒がやってくる。**

v0.2。使い方を案内し、必要な仲間を作る「総えもん」から始めます。[START.md](START.md)を開いて、手元のAIに案内を頼んでください。

## 小さく始め、育てる

総えもんとUI担当が最初からいます。初回の対話で、本人の動機を理解して仕事につなぐ伴走役を最初に作り、必要な業務担当を増やします。練習版には架空の伴走役と見積支援担当を入れています。役割は同じ会話で兼務でき、人数分のAIを常駐させる必要はありません。

全体を支える共通の係はロール文書に、作家などの専門担当は役割と仕事の案内をデスク内にまとめます。別の仕事も同じ担当に頼めます。[共通の係と専門デスク](workspace/agents/roles-and-desks.md)を、作家の例で説明しています。

## 他の仕事場と繋がりたいとき

[どこでもメッシュ](https://github.com/kentaroid-bot/dokodemo-mesh)を使うと、別のどこでもデスクとのあいだに、目的・約束・共同の仕事を置く「中庭」を開けます。各仕事場で考え、中庭へ返し、成果を持ち帰ります。内部の履歴を丸ごと共有する必要はありません。

総えもんへ「他のどこでもデスクと協働したい」と伝えてください。[メッシュ連携の案内](workspace/agents/workflows/mesh-collaboration.md)で、共有範囲・全員合意・巡回担当・終え方を整理します。接続や定期巡回は、この雛形だけでは始まりません。

## 保存先

- workspace/purpose.md：仕事場の目的。本人の意思とAIの解釈を分けた共通原本。
- workspace/onboarding.md：導入の設定と、進捗原本となる導入TASKへの入口。次の会話でも続きから案内するための記録。
- workspace/agents：担当名簿、役割、手順、ひな形。
- workspace/operations：仕事の記録、日報、共有板。
- projects：仕事ごとの成果物と資料の原本。
- console：原本をブラウザで読む画面。
- examples：架空の一件で試す案内。

## 開く・保存する・再開する

Python 3.9以降、外部ライブラリなし。`python3 -B console/server.py`で http://127.0.0.1:8772 を開きます。この端末だけで待ち受けます。

GitHubから本体を取得し、PCでAIに準備を頼むのが基本の入口です。プラグインは不要です。初回の仕事場づくりを最初の仕事として記録し、継続する業務には専用チャットへの引き継ぎも案内します。同じチャットでの兼務も選べます。

[GitHubで保存・別端末で続ける](workspace/recovery/github.md)を標準の選択肢として案内します。[ZIP保存](workspace/recovery/README.md)だけでも始められます。GitHubへの送信やAIアプリの接続・自動起動は設定前です。復元後は共通の記録を読み、初回導入を繰り返さず次の一手から進めます。

詳しい説明：ワークスペース型AI協働ハーネス。役割・ルール・記録・見える画面を、一つの仕事場として持ち運べる雛形です。
